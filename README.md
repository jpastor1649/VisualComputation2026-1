# VisualComputation2026-1
Repository for assignments, projects, and experiments developed in the Visual Computation course (2026-1) at the National University of Colombia.

## Directory Structure

This repository contains 14 workshop directories organized by week following the pattern: `Semana_XX_Nombre_Descriptivo/`

- `XX` = Week number (01-15, excluding week 08)
- `Nombre_Descriptivo` = Descriptive name of the topic

### Workshops:

1. `Semana_01_Fundamentos_Computacion_Visual_Modelado_3D/` - Fundamentals of Visual Computing and 3D Modeling
2. `Semana_02_Geometria_Proyectiva/` - Projective Geometry
3. `Semana_03_Pipeline_Grafico/` - Graphics Pipeline
4. `Semana_04_Computacion_Radiometrica_Color/` - Radiometric Computing and Color
5. `Semana_05_Sintesis_Visual_Texturizado_3D/` - Visual Synthesis and 3D Texturing
6. `Semana_06_Animacion_Cinematica/` - Animation and Kinematics
7. `Semana_07_Visualizacion_Interactiva_Dashboards_3D/` - Interactive Visualization and 3D Dashboards
9. `Semana_09_Fundamentos_Vision_Computador/` - Computer Vision Fundamentals
10. `Semana_10_Vision_Computador_Caracteristicas/` - Computer Vision Features
11. `Semana_11_IA_Vision_Computador/` - AI for Computer Vision
12. `Semana_12_Procesamiento_Avanzado_IA_Visual/` - Advanced Processing and Visual AI
13. `Semana_13_SLAM_Robotica_Visual/` - SLAM and Visual Robotics
14. `Semana_14_Realidad_Extendida_VR_AR_MR/` - Extended Reality (VR, AR, MR)
15. `Semana_15_Aplicaciones_Avanzadas/` - Advanced Applications
