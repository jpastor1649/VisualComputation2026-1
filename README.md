# VisualComputation2026-1
Repository for assignments, projects, and experiments developed in the Visual Computation course (2026-1) at the National University of Colombia.

## Directory Structure

This repository contains 15 workshop directories organized by week following the pattern: `semana_XX_Y_nombre_taller/`

- `XX` = Week number (01-16)
- `Y` = Workshop number within that week
- `nombre_taller` = Workshop name

### Workshops:

1. `semana_01_1_introduccion_processing/` - Introduction to Processing
2. `semana_02_1_formas_colores/` - Shapes and Colors
3. `semana_03_1_transformaciones_2d/` - 2D Transformations
4. `semana_04_1_animacion_interaccion/` - Animation and Interaction
5. `semana_05_1_imagenes_pixeles/` - Images and Pixels
6. `semana_06_1_vectores_fisica/` - Vectors and Physics
7. `semana_07_1_particulas_sistemas/` - Particles and Systems
8. `semana_08_1_opencv_basico/` - Basic OpenCV
9. `semana_09_1_deteccion_contornos/` - Contour Detection
10. `semana_10_1_transformaciones_3d/` - 3D Transformations
11. `semana_11_1_iluminacion_shaders/` - Lighting and Shaders
12. `semana_12_1_texturas_materiales/` - Textures and Materials
13. `semana_13_1_realidad_aumentada/` - Augmented Reality
14. `semana_14_1_machine_learning/` - Machine Learning
15. `semana_15_1_proyecto_final/` - Final Project
